The balance management system uses the updateBalance() function to safely modify the user’s account balance. For withdrawals, the program validates that the requested amount is positive and does not exceed the current balance. For deposits, it ensures the amount is greater than zero. Once validated, updateBalance() adjusts the balance by adding or subtracting the amount, maintaining accurate tracking of funds.

This approach ensures that all financial operations are consistent and prevents invalid transactions, while the updated balance is immediately reflected and recorded in the operation history, providing a clear and reliable record of all account activity.

All inputs requiring an integer use the validateInt() function, which implements a continuous validation loop. The function attempts to convert the input to an integer, and if a ValueError occurs, it displays an error message and prompts the user to enter the value again. This ensures the program never crashes due to type errors and that all entered values are valid.

validateInt() is used for menu selection, the number of operations, withdrawal and deposit amounts, and PIN authentication. Each operation recorded includes the transaction type and amount, creating a reliable and accurate operations history.

All account operations are recorded in the operationsHistory list using the registerOperation() function. Each entry captures the type of transaction—such as balance inquiry, withdrawal, or deposit—and includes the amount involved when applicable. This ensures that every action performed by the user is logged in the order it occurs. By maintaining a detailed and structured history, the program allows users to review all their operations at the end of the session. Combined with input validation and balance management, this system guarantees transparency, accuracy, and reliability in tracking all account activity.
